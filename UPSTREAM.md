# Open-source foundation and attribution

RC Mobile Studio uses Godot Engine as its open-source engine/editor foundation.

Upstream: https://github.com/godotengine/godot

Godot is distributed under the MIT license. Upstream license and copyright notices apply to upstream code used by a build.

RC Mobile Studio is an RC Empire project. RC Empire branding, integration code, configuration, and original mobile UX work are separate from Godot.
