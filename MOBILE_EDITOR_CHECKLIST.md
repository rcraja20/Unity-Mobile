# RC Mobile Studio — Mobile Editor Checklist

- Android editor target: ARM64
- Touch-first navigation: tap, double-tap, long-press, drag
- Multitouch gesture routing: pinch and two-finger pan
- Local project workspace
- Scene document model
- Hierarchy and inspector foundation
- Asset/resource categories
- Script editing session
- Diagnostics console
- Mobile quality presets and profiler foundation
- Android build configuration foundation
- Offline-first policy
- Accessibility settings foundation

This checklist records implemented foundations. It does not claim Unity compatibility or production completeness.
